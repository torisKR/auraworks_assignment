## 면접 준비 순서

1. 현재 설계를 코드와 대조해 실제 구현을 설명합니다.
2. 폴더 구조 확장 설계의 30초 답변과 기존 파일 이동 표를 읽습니다.
3. 향후 계획에서 페이지네이션, 회원 장바구니, 주문·결제 중 두 가지를 골라 변경 지점과 실패 처리를 설명합니다.
4. 면접 문서의 질문에 코드·테스트·DB 정책을 근거로 답합니다.

기능별 폴더 일부와 게스트 입장·OMR 답안 채점·챌린지·알림 화면은 구현했습니다. 향후 계획의 실제 인증·결제·관리자·AI 분석과 신규 테이블은 아직 구현하지 않았습니다. 현재 코드에 있는 것과 문서에 설계한 것을 구분해서 설명합니다.
